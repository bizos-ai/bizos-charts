# 报告版式目录

报告由引擎按版式整页生成，图表槽位使用 [catalog](catalog.md) 中的图型。版式规则与报告 spec 见 [report-mode](references/report-mode.md)。

| 编号 | layout | 名称 | 适合 | 样张 |
|---|---|---|---|---|
| RN | `research-note` | 研究报告 / Research note | 公司、行业、品类深度研究；投资与立项论证 | [中文](templates/reports/research-note.zh.html) · [EN](templates/reports/research-note.en.html) |
| BR | `business-review` | 经营分析报告 / Business review | 月报、季报、店铺与站点复盘 | [中文](templates/reports/business-review.zh.html) · [EN](templates/reports/business-review.en.html) |
| OP | `one-pager` | 一页纸 / One-pager | 品类速览、竞品速写、管理层单页 | [中文](templates/reports/one-pager.zh.html) · [EN](templates/reports/one-pager.en.html) |
| DB | `dashboard` | 数据看板 / Dashboard | 周期监控、全年概览 | [中文](templates/reports/dashboard.zh.html) · [EN](templates/reports/dashboard.en.html) |
| DM | `decision-memo` | 决策备忘录 / Decision memo | 需要拍板的问题与建议 | [中文](templates/reports/decision-memo.zh.html) · [EN](templates/reports/decision-memo.en.html) |
| SR | `study-report` | 科研报告 / Study report | 实验研究、临床前与临床数据、组学结果 | [中文](templates/reports/study-report.zh.html) · [EN](templates/reports/study-report.en.html) |

## 选择

- 读者要“理解并被说服”：研究报告。
- 读者要“知道这个月怎么样、下一步做什么”：经营分析报告。
- 读者只有一页的时间：一页纸。
- 读者会反复回看同一组指标：数据看板。
- 读者要做一个决定：决策备忘录（建议必须明确：做 / 不做 / 有条件地做）。
- 读者要评估一项研究或实验的证据：科研报告（摘要、方法与统计、局限性必备）。
