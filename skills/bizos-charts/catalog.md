| E05 | ROC / PR 曲线<br>ROC / precision–recall curve | 诊断指标或预测模型区分阳性与阴性的能力有多强，哪个模型更好？ | 生物标志物、诊断试验、风险模型的判别力：引擎由原始得分计算 ROC、AUC 与 DeLong 95% CI，两模型可做配对 DeLong 检验；curve:"pr" 画精确率–召回率（阳性稀少时更合适）。 | 只有一个灵敏度/特异度点（用表格）；需要校准度评价（另画校准曲线）。 |
| E06 | 一致性分析（Bland–Altman）<br>Bland–Altman agreement | 两种测量方法的结果是否一致：平均偏倚多大，95% 的差值落在什么范围？ | 新旧检测方法、仪器、评分者之间的一致性；引擎计算偏倚、95% 一致性界限及其置信区间，并检验比例偏倚。 | 用相关系数判断一致性（相关高不代表一致）；两种方法单位不同。 |
| E07 | Q-Q 图<br>Q-Q plot | 数据（或残差）是否服从正态？关联检验的 P 值是否整体膨胀？ | mode:"normal" 检查正态性（残差、测量值）；mode:"pvalue" 检查全基因组或高通量检验的 P 值分布，给出 λGC 与 95% 置信带。 | 比较两组分布（用 E02）；样本 <10。 |
| E08 | 相关矩阵<br>Correlation matrix | 多个变量两两之间的相关方向与强度如何，哪些相关在统计上成立？ | 由原始观测（每行一个样本）计算 Pearson 或 Spearman 相关与 P 值，下三角色阶展示；可做多重比较校正，不显著的格子留白。 | 只关心两个变量（用 R01）；变量 >16 个（先筛选）。 |
| E09 | 交集图（UpSet）<br>Set intersections (UpSet) | 多个集合之间各种交集（如几组差异基因的重叠）各有多少元素？ | 3–8 个集合的重叠：差异基因、突变、客户群、关键词；精确的互斥交集计数，替代面积不准的韦恩图。 | 只有两个集合（用文字或 C03）；交集数量太多且都很小（先过滤）。 |

## B · 生物医学与组学（8）

| 编号 | 图表 | 回答的问题 | 适用 | 不适用 / 改用 |
|---|---|---|---|---|
| B01 | 生存曲线（Kaplan–Meier）<br>Survival curve (Kaplan–Meier) | 随访期间各组的生存（或无事件）比例如何下降，中位生存期相差多少？ | 临床与动物实验的时间–事件数据（总生存、无进展生存、复发、设备故障、客户流失）；引擎由逐例随访时间与结局计算 KM 曲线、删失标记、风险人数表、中位生存期与 log-rank 检验。 | 只有各时点汇总生存率（无法计算删失与检验，用 T01 并注明）；竞争风险明显时（需累积发生率曲线）。 |
| B02 | 剂量反应曲线（IC50 / EC50）<br>Dose–response curve (IC50 / EC50) | 化合物的效力如何（IC50 / EC50 是多少），几种化合物谁更强？ | 细胞活力、酶抑制、受体激动等浓度梯度实验：引擎对全部重复做四参数 logistic 拟合，给出 IC50/EC50 与 95% CI、Hill 斜率，对数浓度轴。 | 浓度点 <5 个或未覆盖上下平台（IC50 不可靠）；时间进程（用 E03）。 |
| B03 | 火山图 / MA 图<br>Volcano / MA plot | 处理前后哪些基因（蛋白、代谢物）显著上调或下调，幅度多大？ | 差异表达、差异蛋白与代谢物：log₂ 倍数变化 × −log₁₀ P，阈值虚线、上下调计数、自动标注最显著的条目；mode:"ma" 画平均表达 × 倍数变化。 | 没有 P 值的倍数变化（用 C04）；条目 <30。 |
| B04 | 曼哈顿图（GWAS）<br>Manhattan plot (GWAS) | 全基因组范围内哪些位点与性状显著关联，信号集中在哪些染色体？ | 全基因组关联分析、eQTL、全外显子负担检验：按染色体位置排列 −log₁₀ P，全基因组显著与提示性阈值线，自动标注各染色体的领头位点。 | 少量候选位点（用 C01 或表格）；P 值未经质量控制。 |
| B05 | 聚类热图<br>Clustered heatmap | 样本和基因按表达谱如何聚类，哪些基因在哪组样本中高表达？ | 表达矩阵（基因 × 样本）：按行 z 分数标准化，行列层次聚类并画树状图，顶部标注样本分组；也适用于蛋白、代谢物、患者特征矩阵。 | 行数 >300（先按方差筛选）；行列有固定顺序且不需聚类（用 H01）。 |
| B06 | 降维图（PCA / UMAP / t-SNE）<br>Embedding (PCA / UMAP / t-SNE) | 样本或细胞按整体特征如何分群，处理组与对照组是否分开？ | 转录组样本 PCA（轴上写解释方差，可加 95% 置信椭圆）、单细胞 UMAP / t-SNE（无坐标刻度，簇标签直接标在簇上）。坐标由分析软件计算后传入。 | 用 UMAP 簇间距离或簇大小下结论；只有两个原始变量（用 R01）。 |
| B07 | 系统发育树 / 聚类树<br>Phylogenetic tree / dendrogram | 各物种、菌株或样本的亲缘关系如何，哪些聚为一支，支持度多高？ | 由 Newick 字符串绘制矩形系统发育树：有枝长时按进化距离（附比例尺），节点显示自展支持率，叶片可按分组着色、可高亮一个分支；也可画样本聚类树。 | 叶片 >150 个（拆分或折叠分支）；需要无根树的径向布局。 |
| B08 | 突变棒棒糖图<br>Mutation lollipop | 突变沿蛋白序列分布在哪里，是否集中在某个结构域或热点位点？ | 肿瘤测序、遗传病变异、定点突变筛选：按氨基酸位置画突变数，下方为蛋白结构域，颜色区分突变类型，自动标注热点。 | 比较多个基因的突变负荷（用 C01）；缺少蛋白长度与结构域坐标。 |
