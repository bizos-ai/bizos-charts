# 按分析问题选图

先问“读者要回答什么问题”，再看数据形状。`node scripts/find-chart.mjs --query "<问题>"` 给候选，以下决策表与 [catalog](../catalog.md) 的“不适用”栏做最终判断。最多比较 3 个候选，选能让结论一眼成立、且不夸大的那张。

## 决策表

| 读者的问题 | 首选 | 备选 / 注意 |
|---|---|---|
| 一个或几个指标随时间怎么走 | T01 折线 | 序列 >6 用 M01 小多图或 highlight；只有几个年度值用 C02 |
| 规模在增长吗，增速/利润率怎样变 | T03 柱线组合 | 只看规模用 C02；两个同单位指标不要双轴 |
| 各期规模与预测，复合增速多少 | C02 柱状图 + `cagr` | 期间多（>24）用 T01 |
| 总量由哪些部分组成，结构在迁移吗 | S01 堆积柱 / T02 堆积面积 | 只看占比用 S02；组成部分有负值用 S03 |
| 一个整体的构成（某一时点） | S04 环形图（≤6 项） | 项目多或份额接近用 C01 |

## 科研与生物医学

| 读者的问题 | 首选 | 备选 / 注意 |
|---|---|---|
| 几个实验组之间有无差异（每组 3–50 个重复） | E01 组间比较 + `test` / `adjust` | 每组更多样本用 E02；只有均值和误差时注明 n 与误差含义 |
| 各组分布形状（双峰、偏态、长尾）有何不同 | E02 小提琴 / 云雨图 | 每组 <20 个用 E01 |
| 测量值随时间、剂量、温度怎样变化 | E03 实验曲线（均值 ± 误差） | 要 IC50 用 B02；日期期间用 T01 |
| 各研究或亚组的效应量与置信区间、合并效应 | E04 森林图（`pool` 合并） | 没有置信区间用 C01 |
| 诊断指标或模型能否区分阳性与阴性 | E05 ROC（阳性稀少用 `curve:"pr"`） | 两模型同一批样本自动做配对 DeLong 检验 |
| 两种测量方法是否一致 | E06 Bland–Altman | 不要用散点图加相关系数判断一致性 |
| 数据是否正态、关联检验 P 值是否膨胀 | E07 Q-Q 图 | GWAS 与 B04 配套 |
| 多个变量两两相关 | E08 相关矩阵 | 只有两个变量用 R01 |
| 几组名单（差异基因、突变、客户群）重叠多少 | E09 UpSet 交集图 | 不画面积不准的韦恩图 |
| 各组生存或无事件比例随时间怎样下降 | B01 Kaplan–Meier | 只有各时点汇总生存率用 T01 并注明无法检验 |
| 化合物效力（IC50 / EC50）谁更强 | B02 剂量反应曲线 | 浓度点 <5 个或无平台时不报 IC50 |
| 哪些基因 / 蛋白显著上调或下调 | B03 火山图（`mode:"ma"` 画 MA 图） | 没有 P 值用 C04 |
| 全基因组哪些位点与性状关联 | B04 曼哈顿图 | 少量候选位点用表格 |
| 样本与基因按表达谱如何聚类 | B05 聚类热图 | 行列顺序固定、不需聚类用 H01 |
| 样本或细胞怎样分群，处理组是否分开 | B06 PCA / UMAP / t-SNE | 坐标由分析软件计算后传入 |
| 物种、菌株或样本的亲缘关系 | B07 系统发育树 | 叶片 >150 个先拆分 |
| 突变沿蛋白怎样分布、热点在哪 | B08 突变棒棒糖图 | 比较多个基因的突变负荷用 C01 |

## 常见误用

- **多选题百分比**（各项独立 0–100%）不是构成，不能用 S02/S04，用 C01。
- **五数概括**不能反推分布形状；只有汇总统计时用表格或 D02 的预计算值，不画直方图。
- **聚合流量**不能补造逐条路径；S07 只表达聚合流量。
- **排名**会掩盖差距；关心差距时用数值图。
- **地区字段**不等于要画地图；只有地理分布本身是结论时才用 G01/G02。
- **饼图**超过 6 块、或需要比较相近份额时一律改用条形图。
- **双轴**：两个同单位指标、或两个绝对额，不得用双轴；改用 C03 或指数化 T04。
- **时间序列**不要用条形图（横向）；类别很多时不要用柱状图（标签放不下），用 C01。
- **小样本实验**不要只画柱高 ± SEM：每组 ≤50 个样本用 E01 画出每个点。
- **显著性**不要只标星号：写检验方法、校正方式和 P 值；多组两两比较必须说明是否校正。
- **方法一致性**不能用相关系数判断（高相关也可能有系统偏倚）：用 E06。
- **UMAP / t-SNE** 的簇间距离和簇大小没有含义，不据此下结论；需要定量比较时用 PCA 或原始指标。
- **韦恩图**超过 3 个集合或需要精确计数时改用 E09。

## 一页放几张图

一个问题 1 张；两到三个结论 2–3 张；完整分析 4–8 张，每张一个独立结论。同一结论不重复画；小多图、前后对照可以复用同一图型。用户指定数量时遵从，但数据撑不起时少画并说明原因。
