# 研报级视觉与口径规范（House style）

引擎已经实现本文的大部分规则；写 spec 时只需提供正确的数据、单位、期间和文字。规则冲突时以本文为准。

## 1. 图表的六个要素

```
图表 3：营收增速 2025 年见底，新品线放量后 2026 年预计回升至 18%      ← 编号 + 结论标题
年度营业收入（百万元，左轴）与同比增速（%，右轴），2020A–2027E          ← 指标、单位、期间
[图]                                                                        ← 图与图例
注：2026E–2027E 为 BizOS 预测；同比按报告期口径                           ← 口径、估算、剔除
资料来源：公司公告，BizOS 整理                                             ← 来源
```

英文版：`Exhibit 3: …`、`Note: …`、`Source: …`。编号在页面与报告中自动连续；单独出图时可用 `no` 指定。

## 2. 标题与副标题

- 标题是**一句可核对的结论**：主语 + 变化/对比 + 数字。例：“美国站贡献全年主要增量，日本站 12 月较 1 月下降 16%”。
- 标题里的每个数字都必须能从本图数据直接算出；做不到就删掉数字或改用能支撑它的图。
- 不写图名（×“销售额趋势图”），不写空话（×“数据分析”），不写数据推不出的因果（×“广告导致销量增长”）；需要因果时写“伴随”“同期”，并在正文说明依据。
- 中文标题不超过约 40 字，英文不超过约 90 个字符；一图只说一件事。
- 副标题写：指标（单位）、范围、期间，必要时写口径（“剔除大促日”“美东时间”）。

## 3. 数字、单位与期间

| 项目 | 规则 |
|---|---|
| 单位 | 数值必须有单位：`unit` 字段或 `format` 自带（%、pct/pp、x、bp、货币）。大数先换算：中文用 万 / 亿 / 百万元，英文用 k / mn / bn；单位写进副标题和轴。 |
| 货币 | 中文：美元、人民币（元），英文：US$、RMB；跨币种汇总须注明汇率与日期。 |
| 百分比 | 字段存百分数（12.5 = 12.5%），默认 1 位小数。比例变化用百分点：中文 `pct`、英文 `pp`；不要把 3.2pct 写成 3.2%。 |
| 倍数 | P/E、EV/EBITDA 等写 `15.6x`；分母为负或缺失写 `n.m.`，不画、不参与均值。 |
| 小数 | 标签保留 2–3 位有效数字；同一列/同一轴小数位一致。 |
| 负数 | 图内用减号 “−”；财务表用括号 (1,234)。 |
| 缺失 | 写 “—”，图中断开或留白，**不补 0**；确实为 0 时写 0。 |
| 合计 | 四舍五入导致合计不等于 100% 或总额时，在注释说明。 |
| 期间 | 年 `2025`，月 `2025-03`（英文 `Mar-25`），季度 `25Q1`（英文 `1Q25`），日 `2025-03-14`；预测期加 `E`（2026E），实际期可加 `A`；滚动十二个月写 TTM。 |
| 增速口径 | 同比（YoY）、环比（MoM/QoQ）写明；复合增速写 CAGR 与起止年。 |

## 4. 坐标轴与比例

- 柱、条、面积、瀑布从 0 开始，柱轴不截断；数值跨度过大时改用对数刻度（须标注）或拆图，而不是截断。
- 折线可以不从 0 开始（引擎在最小值接近 0 时自动包含 0）；变化很小却画满整个纵轴的，必须在副标题写明范围。
- 双轴只用于 T03：左轴绝对额（柱），右轴比率/倍数（线），两轴刻度线对齐，图例标“左轴/右轴”。
- 网格只保留水平浅灰线；零线加深；不画边框、背景色块和三维效果。
- 气泡面积与数值成正比（半径按平方根）；树图面积与数值成正比；地图使用等面积瓦片，避免大州/大省在视觉上被放大。
- 小多图默认共享纵轴；独立纵轴必须在副标题注明“纵轴不同”。

## 5. 颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色（深海军蓝） | `#16365C` | 主序列、主角、合计 |
| 系列 2–5 | `#BD8730` `#4F86C6` `#838F9C` `#2E8C7A` | 依次分配；≤4 个系列在色觉障碍下仍可区分 |
| 系列 6–8 | `#8FB3DB` `#B0574B` `#7A6AA8` | 5 个以上系列必须直接标注 |
| 退后色 | `#C3CAD3` | `highlight` 之外的同业、对照组 |
| 好 / 坏 | `#2A7F62` / `#B83B3B` | 经营增减、达成/未达成；成本类用 `goodDirection:"down"` 反转 |
| 市场涨跌 | 中文默认红涨绿跌，英文默认绿涨红跌 | 仅用于价格（K 线等）；`market:"cn"|"intl"` 可指定 |
| 连续色阶 | 浅蓝 → 深海军蓝 7 档 | 热力、日历、地图；偏态数据用分位数分档并在图例写明阈值 |
| 发散色阶 | 红 ← 浅灰 → 蓝 | 有中性点的数值（增速、相关系数、相对基准） |
| 预测值 | 同色浅色 + 斜线；线条为虚线 | 所有 E 期 |

- 颜色必须对应真实维度；一个序列不用多种颜色；不使用彩虹色、渐变、发光和阴影。
- 主角（我方、标的公司）用 `highlight`，同一实体在整份报告中保持同一颜色（报告渲染自动维护）。
- 品牌色：`palette: {primary: "#hex"}` 只替换主色与色阶；黑白打印：`palette: "mono"`。
- 不能只靠颜色区分：同时有标签、位置或线型。

## 6. 标注

- 优先直接标注（线端标签、柱顶数值），图例只在必要时出现；线条 ≤6 条时引擎自动线端标注。
- 柱顶数值在空间足够时全部显示，否则只保留首末与极值；不要为了“满”缩小字号。
- 参考线写清含义与范围：“同业中位数 5.2%（不含示例公司）”。
- 事件标注用于解释拐点（大促、改版、政策），每图不超过 3 个。
- 图内文字不小于 12px，注释与来源 11px；标签不得重叠（verify.mjs 会检查）。

## 7. 注释与来源

- 注释写：预测与估算方法、口径与剔除项、样本数与抽样方式、汇率、四舍五入、轴不从 0 开始等。多条时编号 (1)(2)。
- 来源写到可追溯的层级：“BizOS 店铺数据（订单、广告）”“公司公告”“用户提供：2025Q4 订单.xlsx”；BizOS 整理或计算的数据加“BizOS 整理/测算”。
- 示例或演示数据必须写“示例数据”，不得冒充真实来源。

## 8. 表格（K02–K04、V02）

- 首列左对齐，数值右对齐；单位写在表头或表注；同列小数位一致。
- 财务表负数用括号；预测列（E）加浅底色；同比行斜体小字。
- 可比公司表：主角置顶加粗，同业均值/中位数单列且不含主角，倍数无意义写 n.m.。
- 敏感性表：基准情形加框；底色表示相对基准的偏离。

## 9. 报告版面

- 页首：`BIZOS RESEARCH · 报告类型` 与日期；结论式主标题（约 27px）、副标题、作者/范围。
- 首屏给出核心观点（3–5 条，带图表编号引用）和关键数据或 KPI；正文章节编号，每章一个论点。
- 结尾：风险提示（如适用）、方法与口径、数据来源列表、声明。正文 14px、行高 1.75。
- 打印：A4，图表不跨页拆分；交互按钮在打印时隐藏。

## 10. 科研与生物医学图（E / B 族）

科研图的检验、区间、拟合与合并估计都由引擎从原始数据计算（`BizosCharts.stats`），方法自动写进注释；`render.mjs` 输出的 `stats` 给出图中每个统计量，标题、摘要与正文直接引用这些数字。

| 项目 | 规则 |
|---|---|
| 样本量 | 每组 n 必须可见（横轴标签、图例或注释）；n 不同的组分别写出。 |
| 误差线 | 注明含义：SD 描述离散，SEM / 95% CI 描述均值精度；中位数配四分位区间。只给汇总值时写明“均值 ± SEM，n = 8”。 |
| 逐点显示 | 每组 ≤ 50 个样本时用 E01 画出每个点；不用只有柱高和误差线的“炸药包”柱图掩盖小样本分布。 |
| 检验 | 写明检验名称与双侧；多组比较做 Holm / Bonferroni / BH 校正，未校正时注释必须写“未做多重比较校正”。用户提供的 P 值必须在 `test` 中写明来源方法。 |
| P 值 | ≥ 0.1 两位小数（0.23）；0.001–0.1 两位有效数字（0.049，不四舍五入成 0.05）；< 0.001 写“P < 0.001”；全基因组用科学计数（P = 2.1×10⁻¹⁴）。星号只作补充（`pStyle:"stars"` 自动附图例），不替代 P 值。 |
| 效应量 | 结论优先报告效应量与 95% CI（均值差、HR、OR、AUC、IC50），显著与否其次。 |
| 刻度 | 比值类（HR、OR、RR）用对数轴、无效线为 1；倍数变化用 log₂；P 值用 −log₁₀；浓度用对数轴并写单位；零浓度无法上对数轴，排除并在注释说明。 |
| 生存分析 | Kaplan–Meier 曲线必须带删失标记、风险人数表、各组中位时间及 95% CI、log-rank 检验；HR 只能来自模型（如 Cox），由用户提供并注明方法。 |
| 剂量反应 | IC50/EC50 写明为拟合曲线顶部与底部中点对应浓度并给 95% CI；超出检测浓度范围的值标“外推”。 |
| 组学 | 写明显著阈值（\|log₂FC\|、校正 P）与校正方法；基因符号斜体；聚类热图写明标准化（行 z 分数）、截断、连接方式与距离；PCA 轴写解释方差；UMAP / t-SNE 不标坐标刻度，不解读簇间距离与簇大小。 |
| 诊断与一致性 | ROC 写 AUC 与 DeLong 95% CI，同一批样本的模型比较用配对 DeLong 检验；阳性稀少时用 PR 曲线。两种方法是否一致用 Bland–Altman，不用相关系数。 |
| Meta 分析 | 写明合并模型（固定 / 随机效应）、异质性 I²、τ²、Q 检验；方块面积与权重成正比。 |
| 颜色 | 科研发散色阶按领域惯例：高 / 正 / 上调 = 红，低 / 负 / 下调 = 蓝（与财务发散色阶方向相反）；分组色沿用研究配色；不用彩虹色阶。 |

## 11. 禁止

饼图超过 6 块、3D 图、渐变/阴影/发光、入场动画、截断柱轴、无单位数字、无来源图表、补 0 的缺失值、编造的区间或预测、同一份交付混用两套配色或两种语言、用外部脚本或字体、手写图表代码绕过引擎检查；科研图中不写 n 与误差线含义、只给星号不给 P 值、未说明检验或多重比较、用相关系数判断方法一致性、彩虹色阶、按 UMAP 距离下结论。
