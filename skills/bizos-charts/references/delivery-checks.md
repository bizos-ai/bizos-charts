# 交付检查清单

`render.mjs` 的规则检查与 `verify.mjs` 的浏览器检查覆盖机器能判断的部分；下面的人工项每次交付都要过一遍。

## 自动检查

```bash
node scripts/render.mjs --spec exhibit.json --out <outputs>/x.html   # 规则检查：有 error 不出文件
node scripts/verify.mjs <outputs>/x.html                              # 1280 / 390 宽度浏览器检查
```

render 的 error 必须修复（缺来源、缺单位、柱轴截断、预测期顺序错误、桥接不平、拆解树不平、构成含负值、漏斗口径不一致、OHLC 不自洽；科研图缺检验方法、置信区间不含估计值、P 值越界、结局不是 1/0、浓度点不足以拟合、PCA 缺解释方差等）。warning 逐条判断：能修就修，不修的在注释说明理由（例如样本不足仍需展示时写明 n）。

verify 的 error（页面报错、外部请求、图未渲染、横向溢出、字号 <11px）必须修复；重叠警告需要换图型、减少标注或拆图。verify 返回 `unverified` 表示本机没有可用浏览器：交付时写明“未做浏览器验证”，不得声称已验证。

## 数据

- [ ] 数据与来源一一对应；用户数据与引擎换算（指数化、占比、同比、CAGR）可从“查看数据”核对。
- [ ] 粒度、期间、币种、口径一致；跨来源合并时已说明对齐方式。
- [ ] 缺失值为空，不是 0；异常值保留并在注释说明处理方式。
- [ ] 预测值标 E 且只出现在实际值之后；区间、情景、拟合说明了方法。

## 图

- [ ] 图型回答的是标题里的问题；没有更直接的图型。
- [ ] 比例诚实：柱从 0 开始；面积编码正确；对数刻度已标注；小多图共享纵轴或已注明。
- [ ] 颜色有含义；主角突出、其余退后；同一实体全报告同色；系列多时已直接标注。
- [ ] 标签可读、无重叠；长类别名换行而不是缩小字号。

## 文字

- [ ] 标题是结论，标题中的每个数字能从本图算出；没有数据推不出的因果。
- [ ] 副标题有指标、单位、期间；注释有口径与方法；来源完整。
- [ ] 语言单一；术语与单位前后一致（pct/pp、x、n.m.、—）。

## 科研图（E / B 族）

- [ ] 每组 n、误差线含义（SD / SEM / 95% CI / 四分位区间）在图上或注释中可见。
- [ ] 检验方法、双侧与否、多重比较校正写明；用户提供的 P 值写明来源方法。
- [ ] P 值按规范格式，标题与图中数字相同（引用 `render.mjs` 输出的 `stats`）；星号不替代 P 值。
- [ ] 比值、倍数、P 值、浓度使用对数刻度并标注；阈值（\|log₂FC\|、校正 P、5×10⁻⁸）画出并写明。
- [ ] 生存曲线带删失标记与风险人数表；IC50 未外推或已标“外推”；UMAP 未解读簇间距离。

## 报告（报告模式另查）

- [ ] 核心观点引用的图表编号正确；同一指标在全文数值一致。
- [ ] 方法与口径、来源列表、风险提示齐全；声明未被删除。

## 交付

- [ ] HTML 离线可打开，未引用任何外部脚本、字体、图片或地图文件。
- [ ] 用宿主内置预览打开（BizOS：`create_artifact` / `update_artifact` 的 `html_path`）；没有内置预览时只给文件路径，不调用外部浏览器。
- [ ] 答复中说明结论、来源、口径与限制；需要插入 PPT/文档时提供 SVG（`render.mjs --svg`）或页面内的 PNG 导出。
